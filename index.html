🛠️ Troubleshooting

If you encounter any issues, try these common solutions:

🔹 Problem: Windows Defender blocks the download or installation
Solution: Click "More info" and then "Run anyway" - this is a false positive from Windows security.

🔹 Problem: Application won't start
Solution: Make sure you have the latest version and are running it as administrator (right-click, "Run as administrator").

🔹 Problem: Server is slow
Solution: Close any unnecessary programs, check your internet connection, and ensure you have at least 2GB of free RAM.

🔹 Problem: Update fails
Solution: Temporarily disable your firewall and antivirus, then try again. Re-enable them after the update.

🔹 Problem: Game won't connect
Solution: Ensure your Brawl Stars client is version 24 and that your server is running properly.
